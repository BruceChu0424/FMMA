FMMA includes and links against code written by other people. This file
lists all of it, and what following from it.

## Summary of obligations

**The `marketstream` binary is a combined work with mongoose, which is
GPL-2.0-only. The combined binary is therefore GPL-2.0, and this project is
licensed GPL-2.0 to match** — see [LICENSE](LICENSE).

That is a consequence of a dependency, not a preference. If the team would
rather license their own work differently, the options are to replace
mongoose with a permissively licensed stack (libwebsockets is LGPL-2.1,
civetweb is MIT) or to obtain a commercial mongoose licence from Cesanta.

## OpenSSL

| | |
|---|---|
| Linked as | `-lssl -lcrypto` |
| Not vendored | supplied by the target distribution (`libssl-dev`) |
| Licence | Apache-2.0 (OpenSSL 3.x) |
| Upstream | https://www.openssl.org/ |

Apache-2.0 and GPL-2.0 are generally considered incompatible for
distribution as a combined work. For this project it does not arise: OpenSSL
is a system library on the target, the binary is not redistributed, and the
GPL's system-library exception covers the ordinary case. If `marketstream`
were ever distributed as a binary, this would need a proper look — either an
OpenSSL exception in the licence grant, or GnuTLS/mbedTLS instead.

### Four hand-supplied files

Quartus Prime **Lite** does not ship the EMIF/UniPHY generation stack, so
four files a full generation would have produced were taken from a public
mirror of equivalent Qsys output (the `aekanman/FPGA-video-decoder`
repository) and are listed directly in `HFTTop.qsf`:

* `altera_mem_if_hard_memory_controller_top_cyclonev.sv`
* `altera_mem_if_oct_cyclonev.sv`
* `altera_mem_if_dll_cyclonev.sv`
* `HPSfgpa2_mm_interconnect_0_avalon_st_adapter_error_adapter_0.sv`

They carry the same Intel copyright and licence as the rest of the generated
tree; they are Intel's files, obtained from a third-party copy rather than
generated locally. Port lists were checked against the instantiations in
`hps_sdram.v` before they were accepted.
[docs/BUILD-NOTES.md](docs/BUILD-NOTES.md) §2 has the detail, including the
warning to delete them before regenerating.
